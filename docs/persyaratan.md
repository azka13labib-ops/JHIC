# Ringkasan Persyaratan & Panduan Lomba JHIC 2.0 (Web Development)

Dokumen ini adalah ringkasan yang diekstrak dari *Web Development Guideline - Jagoan Hosting Innovation Competition 2.0*. Gunakan dokumen ini sebagai ceklis persiapan tim SMA PGRI 1 Lumajang.

## 1. Spesifikasi Fitur Website Wajib
Berdasarkan **Halaman 7**, website yang dibuat harus mencakup 5 fitur utama:
- [x] **Landing Page Utama:** Memuat Lulusan Terbaik, Kerja Sama Industri, Jurusan, dan Prestasi.
- [x] **Website PPDB:** Sistem Penerimaan Peserta Didik Baru.
- [x] **Promosi Produk Unggulan (BLUD):** Menampilkan karya/produk unggulan sekolah.
- [x] **PKL & Career Center (BKK):** Portal lowongan kerja dan alumni.
- [x] **AI Integrated Website (ChatBot):** Memiliki asisten AI interaktif (Sudah ada via `FloatingChatbot`).
