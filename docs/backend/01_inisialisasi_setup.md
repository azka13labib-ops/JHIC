# Task Backend: Fase 1 - Inisialisasi & Setup Dasar

## Deskripsi
Setup awal untuk backend Laravel, termasuk konfigurasi keamanan, database, dan environment.

## Todo List
- [ ] Setup Laravel Sanctum untuk Autentikasi API (API Tokens).
- [ ] Konfigurasi CORS agar bisa menerima request dari domain/port Next.js (port 3000).
- [ ] Buat database MySQL di Laragon dan konfigurasikan `.env`.
- [ ] Buat Model & Migration untuk `User` (Siswa dan Admin).
- [ ] Setup *Role & Permission* (misal pakai `spatie/laravel-permission`).
- [ ] Konfigurasi Laravel Storage (jalankan `php artisan storage:link`) untuk upload file.
- [ ] (Opsional) Setup Redis untuk Caching dan Queue.
